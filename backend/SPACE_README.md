# Portfolio Risk Analyzer API

FastAPI backend for Portfolio Risk Analyzer. It computes portfolio risk, sector exposure and
drawdown from uploaded holdings, and can add AI insights. Not investment advice.

Health check: `GET /health`. Source and docs: see the GitHub repository this Space is deployed from.
